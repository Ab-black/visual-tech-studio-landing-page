# Visual Tech Studio Landing Page

A modern, responsive landing page for **Visual Tech Studio**, built for the internship landing-page assignment using semantic HTML5, CSS3, and Vanilla JavaScript.

## Project Structure

```text
visual-tech-studio-landing-page/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── fonts/
└── README.md
```

## Page Structure

- Header and primary navigation
- Hero section
- About / Studio section
- Services section
- Selected Work section
- Visual Tech Studio approach statement
- Why Visual Tech Studio section
- Project CTA section
- Footer

## Development Practices

- Semantic HTML5 elements and accessible navigation
- Descriptive class and ID names using kebab-case
- CSS variables for shared design tokens
- Vanilla JavaScript with small, focused responsibilities
- Responsive-first layout with Flexbox, CSS Grid, and media queries
- Progressive enhancement for animations and navigation behavior
- `prefers-reduced-motion` support
- No inline CSS or inline JavaScript
- Assets organized by type under `assets/`

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
